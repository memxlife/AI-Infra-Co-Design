# Design Optimization

This area covers research on mathematical formulations and agent-assisted exploration of hardware–software designs for AI infrastructure.

The planned scope includes operator transformations, tensor partitioning and placement, memory reuse, instruction scheduling, and architectural resource choices. Candidate designs will exchange verification evidence with the design-verification work.

## Experiments

[EPFL logic-synthesis recipe search](../eve-experiments/epfl/) compares evolving
and fixed agent guidance with sampled, complete or absent execution history.
The experiment includes a bilingual four-arm report, figures, configurations
and commands using the public [EvE engine](https://github.com/scaling-group/eve).
