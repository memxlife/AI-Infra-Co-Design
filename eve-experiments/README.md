# EvE experiments for design optimization

Experiments using [EvE](https://github.com/scaling-group/eve) to search for
hardware design improvements.

- **[EPFL logic synthesis](epfl/):** four twenty-round runs comparing evolving
  or fixed agent guidance and access to previous execution history.
  [English report](epfl/reports/comparison.en.md) ·
  [中文报告](epfl/reports/comparison.zh-CN.md)

Each task includes reports, configurations and commands for running a new
experiment. EvE is downloaded from its public repository during setup.
